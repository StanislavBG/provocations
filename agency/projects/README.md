# Agency Projects

Each subdirectory represents a project/brand the agency promotes.

## Adding a New Project

1. Create a new directory: `projects/my-project/`
2. Create `projects/my-project/CLAUDE.md` with:
   - What the project is
   - Who the target audience is
   - Brand voice guidelines (how the project "sounds")
   - Target communities (subreddits, X accounts to engage with, Facebook groups)
   - Keywords and topics to search for
   - What NOT to do (specific restrictions)
3. The agency reads ALL project CLAUDEs on each cycle and decides which projects have opportunities

## Example Structure

```
projects/
  my-saas-tool/
    CLAUDE.md          # Full project brief
  my-blog/
    CLAUDE.md          # Full project brief
  my-consultancy/
    CLAUDE.md          # Full project brief
```
